# Set Operations CLI in Python

A command-line interface (CLI) application implemented in Python that calculates discrete mathematical operations on user-defined sets without relying on built-in set methods, demonstrating core algorithmic logic and manual data structure parsing.

## Features

- **Union ($A \cup B$):** Combines unique elements from both sets.
- **Intersection ($A \cap B$):** Identifies elements present in both sets.
- **Difference ($A - B$):** Finds elements present in Set A but excluded from Set B.
- **Absolute Complement ($A^c$):** Determines elements in the Universal set not present in Set A.
- **Symmetric Difference ($A \Delta B$):** Extracts elements in either Set A or Set B, but not in both.

## Tech Stack

- **Language:** Python 3.x
- **Paradigm:** Procedural Programming & Algorithmic Logic
